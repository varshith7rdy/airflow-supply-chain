# Automated Supply Chain MRP & Vendor PO Pipeline (Apache Airflow)

A lightweight, production-grade Apache Airflow pipeline simulating an end-to-end **Material Requirements Planning (MRP)** workflow for an e-commerce warehouse. The pipeline ingests daily sales and inventory snapshots, factors in supplier lead times and minimum order quantities (MOQs), calculates reorder points (ROP), auto-generates vendor Purchase Orders (POs), and logs executive audit reports.

---

## 📌 Features & Business Logic

1. **Daily Operations Ingestion (`ingest_daily_operations`)**:
   - Ingests `sales_yesterday.csv`, `inventory_snapshot.csv`, and `suppliers_master.csv`.
   - Validates column schemas, data types, and checks for missing/corrupt values.

2. **MRP Reorder & Risk Calculation (`calculate_net_requirements`)**:
   - Calculates **Daily Burn Rate** per SKU.
   - Computes **Reorder Point (ROP)**:
     $$\text{ROP} = (\text{Daily Burn Rate} \times \text{Supplier Lead Time}) + \text{Safety Stock}$$
   - Identifies items where $\text{Current Stock} \le \text{ROP}$.
   - Rounds required replenishment quantities up to the supplier's **Minimum Order Quantity (MOQ)**:
     $$\text{Order Qty} = \max\left(\text{MOQ},\; \lceil \frac{\text{Target Buffer} - \text{Current Stock}}{\text{MOQ}} \rceil \times \text{MOQ}\right)$$
   - Flags **Critical Stockout Risk** SKUs where stock will reach zero before supplier lead time elapses ($\text{Current Stock} < \text{Daily Burn Rate} \times \text{Lead Time}$).

3. **Vendor Purchase Order Generation (`generate_vendor_purchase_orders`)**:
   - Groups flagged replenishment items by `supplier_id`.
   - Generates individual vendor PO files in `output/purchase_orders/po_supplier_<supplier_id>.csv` complete with item costs, total order value, and required delivery dates.

4. **Audit Logging & Procurement Webhook Notification (`audit_and_notify_procurement`)**:
   - Appends executive summary report to `output/logs/procurement_summary.log`.
   - Logs structured JSON webhook payload simulating an alert dispatched to a procurement Slack/Teams operational channel.

## 🚀 Setup & Execution Instructions

### 1. Prerequisites & Virtual Environment

Ensure Python 3.10+ is installed. Clone the repository and initialize the virtual environment:

```bash
# Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Upgrade pip and install dependencies
pip install --upgrade pip setuptools wheel
pip install -r requirements.txt
```

### 2. Generate Mock Data (Optional Manual Step)

Input fixtures can be pre-populated manually or will automatically be generated by the DAG on first run:

```bash
python3 include/scripts/generate_mock_data.py
```

This creates:
- `include/data/sales_yesterday.csv`
- `include/data/inventory_snapshot.csv`
- `include/data/suppliers_master.csv`

## 🧪 Testing & Running the Pipeline

### Direct Python Verification (No Airflow DB needed)

You can verify the end-to-end data processing logic directly using python:

```bash
python3 include/scripts/mrp_calculator.py
```

### Airflow DAG Validation & Testing

Initialize local Airflow standalone / test environment:

```bash
export AIRFLOW_HOME=$(pwd)

# Initialize database
airflow db init

# Test individual DAG tasks
airflow tasks test supply_chain_mrp_pipeline ingest_daily_operations 2026-01-01
airflow tasks test supply_chain_mrp_pipeline calculate_net_requirements 2026-01-01
airflow tasks test supply_chain_mrp_pipeline generate_vendor_purchase_orders 2026-01-01
airflow tasks test supply_chain_mrp_pipeline audit_and_notify_procurement 2026-01-01

# Or run Airflow Standalone Server
airflow standalone
```

Access the Airflow UI at `http://localhost:8080` to trigger `supply_chain_mrp_pipeline`.
